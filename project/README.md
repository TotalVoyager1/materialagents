# Мультиагентный ИИ-оркестратор

Минимальное веб-приложение на Python и Streamlit для поэтапной подготовки и проверки учебных проектов через OpenRouter.

## Запуск

1. Установите Python 3.10 или новее.
2. Создайте виртуальное окружение и установите зависимости:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и укажите ключ OpenRouter в `OPENROUTER_API_KEY`. По умолчанию используется `google/gemma-4-26b-a4b-it`; модель можно заменить переменной `OPENROUTER_MODEL`. Для вызовов может потребоваться доступный баланс OpenRouter.
4. Запустите интерфейс:

   ```powershell
   streamlit run app.py
   ```

Не помещайте API-ключ в исходный код или репозиторий. Если ключ уже публиковался, отзовите его и создайте новый.

## Как устроена оркестрация

- `Planner` строит план; `Researcher` выполняет TF-IDF-поиск по индексированным локальным документам.
- `Writer` формирует редактируемый черновик; пользователь может поправить результаты каждого этапа перед продолжением.
- `Critic`, `Tester`, `CodeReviewer` и `Summarizer` выполняются отдельными шагами и получают результаты предыдущих агентов.
- `Formatter` собирает Markdown и формирует Markdown, JSON с логами, PDF и DOCX.
- Запросы к OpenRouter используют `google/gemma-4-26b-a4b-it`, потоковую выдачу и параметр `reasoning: {"enabled": true}`. Модель закреплена явно, чтобы роутер не выбрал другой вариант. В интерфейс выводится только текст ответа, не внутренние reasoning-данные; пустые ответы, safety-метки и текст внутренних рассуждений отбрасываются с повторной попыткой.
- Загрузка поддерживает TXT, Markdown, PDF, DOCX, CSV, JSON и Python; кодовые файлы используются для статического ревью.
- Вкладка анализа CSV показывает профиль данных, кластеризацию K-means, опциональную классификацию Random Forest и простой линейный прогноз по индексу строк.
- Логирует агента, этап, время выполнения, статус и объём результата. Данные документов и анализ остаются локальными; запросы к OpenRouter включают текст переданных этапу выдержек и результатов.
- При исследовании и проверке кода переданные фрагменты документов/кода отправляются в OpenRouter и выбранному провайдеру модели. Не загружайте конфиденциальные данные.

Для запуска тестов: `python -m unittest discover -s tests`.
